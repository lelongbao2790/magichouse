# magichouse

This project uses **AI-DLC v2.7.1** for structured development workflows.

The framework is installed in `.claude/` — see `.claude/CLAUDE.md` for full usage instructions, prerequisites, and commands.

## Quick Start

Run `/aidlc` followed by a scope or project description to begin.
Run `/aidlc --doctor` to validate your setup.
Run `/aidlc --version` to print the framework version.
