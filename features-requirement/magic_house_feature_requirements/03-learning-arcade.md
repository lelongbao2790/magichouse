# Feature: Learning Arcade

## Goal

Turn normal quiz questions into short educational mini-games.

## Game Ideas

### Balloon Pop

Show a question and several answer balloons. The child pops the correct
answer.

### Catch the Answer

Move a character to catch the correct answer.

### Monster Battle

Correct answers reduce the monster's health.

### Treasure Hunt

Solve several questions to open a treasure chest.

### Matching Game

Match words, pictures, numbers, or equations.

## Subject Examples

-   Math: Addition, Subtraction, Times Table
-   English: Vocabulary, question words, picture matching
-   Vietnamese: Vocabulary, sentence ordering, reading
-   Preschool: Shapes, Colors, Animals

## Rewards

Coins are awarded based on difficulty and completion.

## MVP

Reuse the existing question system and implement 2 mini-game
presentation modes first: Balloon Pop and Matching Game.
