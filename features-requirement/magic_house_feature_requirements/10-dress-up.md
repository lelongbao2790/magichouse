# Feature: Dress Up

## Goal

Expand character customization beyond stickers.

## Customization

-   Hair styles
-   Hats
-   Shirts
-   Dresses
-   Pants
-   Shoes
-   Glasses
-   Accessories

## User Flow

1.  Earn coins from learning.
2.  Buy clothing in the Magic Shop.
3.  Open Creative Room.
4.  Equip items on the selected character.
5.  Save the outfit.

## Learning Connection

Special clothing can also be unlocked through achievements or learning
milestones.

## MVP

5--10 items per category, owned-item inventory, equip/unequip behavior,
and saved outfit.
