# Feature: Adventure Map

## Goal

Give children a visible progression path instead of only selecting
isolated quizzes.

## Example Worlds

1.  Magic House
2.  Number Forest
3.  Word Castle
4.  Ocean World
5.  Space World

## Example: Number Forest

-   Addition Challenge
-   Subtraction Challenge
-   Times Table Challenge
-   Boss Challenge
-   Treasure Chest

## Unlocking

Children complete activities to unlock the next location.

## Rewards

-   Coins
-   Stickers
-   Furniture
-   Pet items
-   Badges
-   Treasure chests

## Learning Connection

Each map location represents a learning skill or subject.

## MVP

One world with 5--8 nodes, locked/unlocked states, progress tracking,
and one final treasure chest.
