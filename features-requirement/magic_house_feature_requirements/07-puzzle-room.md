# Feature: Puzzle Room

## Goal

Provide non-traditional learning activities focused on logic, memory,
and problem solving.

## Game Types

-   Jigsaw Puzzle
-   Memory Card Matching
-   Find the Difference
-   Pattern Completion
-   Number Sequence
-   Word Matching
-   Shape Matching

## Difficulty

Adjust puzzle complexity for Preschool, Grade 1, and Grade 2.

## Rewards

Award a small number of coins for completion, with bonuses for harder
puzzles.

## MVP

Memory Card Matching and Pattern Completion with three difficulty
levels.
