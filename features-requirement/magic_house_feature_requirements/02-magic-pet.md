# Feature: Magic Pet

## Goal

Let children adopt and care for a virtual pet while connecting pet
rewards to learning.

## User Flow

1.  Choose a pet.
2.  Complete learning activities.
3.  Earn coins, food, and pet items.
4.  Feed, clean, dress, and play with the pet.
5.  Unlock new pet accessories.

## Example Pets

-   Dog
-   Cat
-   Rabbit
-   Panda

## Pet Activities

-   Feed
-   Bath
-   Play
-   Sleep
-   Dress Up

## Learning Connection

Example: Complete 5 Addition questions to earn an apple for the pet.

## Rewards

-   Coins
-   Food
-   Clothes
-   Toys
-   Pet accessories

## MVP

One pet, hunger/happiness indicators, food inventory, basic accessories,
and rewards from learning activities.
